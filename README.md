# Kubik-ESP32

Мінімальний прототип Кубика для **Waveshare ESP32-S3 Touch AMOLED 2.16**.
Основна розробка прошивки та мережевого протоколу тепер ведеться тут.

## Можливості

- Геометричний AMOLED-персонаж із морганням і станом сну.
- Сенсорний дотик → подія в настільному застосунку.
- Wi-Fi, отримання стану через HTTP, індикатор Offline після втрати зв'язку.
- Передача готових рішень DeskOne: локація, емоція, предмет, носимі аксесуари.
  У прототипі аксесуари відображаються текстом із прозорістю предмета.
- Авторизація токеном, обмежені черги, дедуплікація подій.

## Збірка та прошивка

ESP-IDF **5.5.5**, Waveshare BSP **2.0.1**, LVGL **9.3.0**.

```text
cd firmware/kubik-esp32
idf.py set-target esp32s3
idf.py menuconfig
idf.py build
idf.py -p COM5 flash monitor
```

У меню **Kubik companion** задайте Wi-Fi, URL ПК і токен.
Повна [інструкція прошивки та перевірки](docs/kubik-esp32.md).

## Зв'язок із DeskOne

DeskOne залишається джерелом станів, розкладу, правил аксесуарів та дозволів
сповіщень. Цей репозиторій містить прошивку й Python-сервіс протоколу.
[Інструкція інтеграції](docs/deskone-integration.md).

## Тести

Python **3.12**, без сторонніх Python-залежностей:

```text
python -m unittest discover -s tests -v
```

GitHub Actions перевіряє Python та збирає ESP32-S3.
CI-прошивка не містить Wi-Fi-пароля й токена; для підключення потрібна
локальна конфігурація та повторна збірка.
