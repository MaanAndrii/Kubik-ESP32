# Подальша розробка

1. Реалізовано: автономний демонстраційний сервер для тестування плати без DeskOne.
2. Перевірка фізичної плати: старт, AMOLED, сенсор, Wi-Fi та відновлення зв'язку.
3. Візуальні аксесуари замість тексту, після узгодження вигляду персонажа.
4. Налаштування мережі без перекомпіляції й без зберігання секретів у Git.
5. Діагностика з'єднання та обробка помилок протоколу.
6. Перевірка пам'яті, стабільності та батарейного режиму.

Протокол v1 зберігає DeskOne джерелом правил. Розклад і матриця аксесуарів
не дублюються в прошивці. Фізичні результати записуються окремо від CI.
